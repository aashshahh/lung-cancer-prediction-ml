# Lung Cancer Prediction (Original 3rd Year Project, Updated in 2025)

This project builds a machine learning model to predict the likelihood of lung cancer based on survey responses.  
The original version was built during my 3rd year of engineering. In 2025, I expanded and reorganized the project into a cleaner, modular, research-ready pipeline.

## Project Structure
- **data/** – raw dataset  
- **notebooks/** – development and analysis notebooks  
- **src/** – preprocessing + training scripts  
- **models/** – saved models
