# Lung Cancer Risk Prediction (2024 Version)

This folder contains the original implementation I built in 2024 during my undergraduate studies.  
The research was later published in **Techno-Societal 2024**.

---

## Project Summary (2024)
The 2024 version used a questionnaire-based dataset with 15 lifestyle and symptom features to predict lung cancer risk.

### Dataset Features
- Age, Gender  
- Smoking, Yellow Fingers  
- Anxiety, Peer Pressure  
- Fatigue, Allergy  
- Wheezing, Coughing  
- Chest Pain, Swallowing Difficulty  
- Alcohol consumption  
- Chronic disease  
- Shortness of breath  

---

## ML Methods (2024)
Models trained:
- Logistic Regression  
- SVM  
- Decision Tree  
- Random Forest  
- KNN  
- Naive Bayes  
- XGBoost  

### Best Model:
**Random Forest — 94.96% accuracy**
